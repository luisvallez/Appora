# Appora

Aplicación de escritorio para Windows que reúne las actualizaciones disponibles de **winget**, **Microsoft Store** y **Windows Update** en un solo lugar, para que decidas qué instalar.

Desarrollada por **Luisvallez** — **Luis Fernando Valle Zamorano**.

## Descarga

Las versiones instalables de Appora se publican únicamente en la sección **Releases** de este repositorio.

- `Appora.exe` — instalador para Windows.
- `Appora.msi` — paquete de instalación para Windows.

Descarga siempre la versión más reciente desde **Releases**. No se distribuye código fuente en este repositorio.

## Actualizaciones

Appora utiliza **Tauri Updater** para detectar e instalar nuevas versiones publicadas en GitHub Releases.

Cuando exista una actualización compatible, la aplicación podrá descargarla e instalarla desde la propia interfaz.

## Requisitos

- Windows 10 u 11 de 64 bits.
- `winget` y PowerShell disponibles en el sistema.
- Conexión a Internet para consultar actualizaciones.

## Características

- Detección de actualizaciones de winget, Microsoft Store y Windows Update.
- Selección individual o masiva de actualizaciones.
- Instalación por lotes con progreso y registro de cada paquete.
- Historial de instalaciones y posibilidad de revertir versiones compatibles.
- Gestión de paquetes ignorados.
- Interfaz en español e inglés.
- Temas claro y oscuro.
